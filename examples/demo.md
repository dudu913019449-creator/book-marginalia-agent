# Demo

This fixture uses invented text and no personal information.

## Passage

> A plan becomes useful only when reality is allowed to disagree with it.

## Reader context

The reader explicitly said in the current conversation that they are preparing to show a small prototype.

## Balanced marginalia

**Meaning:** A plan is not a prediction to defend; it is a hypothesis that becomes useful when evidence can change it.

**Personal connection:** This connects to the reader's stated prototype work: showing the smallest working version creates the disagreement that a private plan cannot. Source: current conversation.

**Challenge:** Constantly changing direction can also prevent a plan from accumulating evidence. The missing distinction is between revising from feedback and reacting to noise.

**Takeaway:** Decide in advance which observation would make the next version meaningfully different.

**Page-side note:** A plan learns only when it can lose an argument with reality.
